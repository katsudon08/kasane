# プログラム

ロボットを動かすプログラムの仕様を記します。

**QR カード**をカメラにかざすことでプログラムを作ります。
一枚のカードは一つの**コマンド**に対応し、コマンドは以下の六種類です。

| コマンド   | 説明                                                                                                                                 |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 前にすすむ | ロボットを一マス前に進める                                                                                                           |
| 右にまがる | ロボットを時計回りに 90 度回転させる                                                                                                 |
| 左にまがる | ロボットを反時計回りに 90 度回転させる                                                                                               |
| 穴をうめる | ロボットの前のマスが**穴**なら**床**に変える。それ以外なら何もしない                                                                 |
| くりかえす | **おわり**までのコマンド（**くりかえす**を含む）を指定回数くり返す。このコマンドだけ、読み込み時にモーダルウィンドウで回数を入力する |
| おわり     | **くりかえす**の範囲の終わりを示す                                                                                                   |

## ロックとバージョン

- ロックされたプログラムは変更できません。
- **予測プログラム**は、ロックされるたびに**バージョン**として記録されます。いつロックされ、どのバージョンが使われるかは [児童フロー](student-flow.md) を参照してください。
