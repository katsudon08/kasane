## システム構成

```
児童A ブラウザ --- バリア同期 --- 児童B ブラウザ    教師 ブラウザ
     |                              |               |
     |                              |               |
     +------------------------------+---------------+
                              |
                             WSS
                              |
                       サーバー (1プロセス)
                              |
                          データベース
```

ペアとなる児童同士の間に直接の接続はなく、**すべての通信はサーバーを経由します**。
教師も同じサーバーに接続します。

## ブラウザ

**入出力のみを担います。**

- 児童および教師の操作を受け取り、サーバーへ送る
- サーバーから受け取った結果を描画する

進行の判断とプログラムの実行は行いません。
ブラウザは自ら状態を決めず、**サーバーから受け取った状態に従います**。

## サーバー

**判断と計算を担います。**
メモリを共有するために、**1プロセス**で児童と教師の両方の接続を受け持ちます。

- 接続を確立・維持し、接続の生死を把握する
- 教師・児童の接続と児童同士の接続を、**別のエンドポイント**として受け持つ
- [児童フロー](../spec/児童フロー.md)を進める判断を行う（**バリア同期**）
- プログラムを解釈し、展開されたコマンド列をブラウザに渡す
- 誰に何を送ってよいかを決定し、送信する
- 接続に関する情報のみをメモリ上に保持する

ブラウザに計算を任せず、**同じ処理が分散しない状態**を保ちます。

## データベース

**状態と記録の保持を担います。**

- [児童フロー](../spec/児童フロー.md)の進行状態を **SoT** として保持する
- 作成されたプログラムとその履歴を永続化する
- 同時に届いた更新に対して**一貫性を保証する**

サーバーは状態を**変更する判断**を行い、データベースは状態を**保持して整合を守ります**。
