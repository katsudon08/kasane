# 児童が授業内でプレイする迷路の仕様

迷路は**5 × 5 ~ 7 × 7**のマスのグリッドとして構成されています。
また、**1F ~ 3F**の層構造を想定しています。

## マスの種類

迷路内に設置されているマスの種類は以下の8種類です。

| マス | 説明 |
| --- | --- |
| スタート | ロボットが最初に配置されるマス |
| ゴール | このマスを通過するとゲームクリア |
| 床 | ロボットが移動できるマス |
| 壁 | ロボットがぶつかるとゲームオーバー |
| 穴 | ロボットが通過すると落下してゲームオーバー |
| ボタン | このマスを通過することで、相手の**鍵**のロックを外すことができる |
| 鍵 | このマスを通過することで、**ゴール**のロックを外すことができる |
| テレポート (実装するかどうか未定です) | ロボットを上下の階層に移動させる |

## スタート・ゴール・ボタン・鍵について

**スタート・ゴール・ボタン・鍵**は各児童ごとに一つずつ設置されています。
これらのマスについては、自分のものだけ利用することができ、相手のものを通過しても**床**と同様の扱いになります。

ボタンを押すと相手の鍵の**ロックが外れ**、相手が鍵を取得できるようになります。

鍵を取得することで、自分のゴールをクリアすることができます。
鍵はXターン後に**消滅**します。 (Xの数字は変更可能です)
