# 技術スタック

本サービスで採用する技術について記述します。
構造については[アーキテクチャ](アーキテクチャ.md)を参照してください。

**Better-T Stack**を使用して基盤を構築します。
Better-T Stack で満たせないものは個別に構築します。

## 共通

| 領域 | 採用 |
| --- | --- |
| 言語 | TypeScript 6.x |
| パッケージマネージャ | pnpm |
| モノレポ | pnpm workspaces + Turborepo |
| ツールのバージョン管理 | mise（Node / Bun） |
| スキーマ・検証 | zod |
| 環境変数の検証 | t3-env |
| Linter | oxlint |
| Formatter | oxfmt |
| Git Hooks | lefthook |

pnpm のバージョンは `package.json` の `packageManager` で指定します。

## リポジトリ構成

パッケージ名のスコープは `@kasane` とします。

```
kasane/
├─ apps/
│  ├─ web/    フロントエンド
│  └─ api/    バックエンド
└─ packages/
   └─ core/   web と api で共有する型・スキーマ
```

`packages/` には、複数のワークスペースから利用されるものだけを置きます。

## `apps/web`

| 領域 | 採用 |
| --- | --- |
| 開発ツールのランタイム | Node |
| フレームワーク | React |
| ルーティング | TanStack Router |
| ビルドツール | Vite |
| UI コンポーネント | Mantine |
| スタイリング | インラインスタイル（基本） / vanilla-extract |
| 3D 描画 | React Three Fiber |
| QR 読み取り | @yudiel/react-qr-scanner |
| コンポーネントカタログ | Storybook |
| テスト | Vitest |
| デプロイ | Cloudflare Workers |

## `apps/api`

| 領域 | 採用 |
| --- | --- |
| ランタイム | Bun |
| フレームワーク | Elysia |
| リアルタイム通信 | WebSocket（Bun標準） |
| データベース | PostgreSQL |
| ORM | Drizzle ORM |
| DBドライバ | pg |
| マイグレーション | drizzle-kit |
| テスト | bun test |
| デプロイ | Railway |
| DBホスティング | Neon（本番） / Docker Compose（ローカル） |

マイグレーションは、MVP完成までは`push`、完成後は`generate` + `migrate`で運用します。

## `packages/core`

| 領域 | 採用 |
| --- | --- |
| 内容 | `apps/web`と`apps/api`の間でやり取りするメッセージの型・スキーマ |
| テスト | bun test |

## 導入しないもの

- 認証ライブラリ（児童は参加コードと出席番号で識別します）
- 状態管理ライブラリ（必要になった時点で導入します）
