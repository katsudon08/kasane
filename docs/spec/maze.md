# 迷路

児童が授業内で取り組む迷路の仕様を記します。

迷路は **5 × 5 〜 7 × 7** のマスのグリッドで、**1F 〜 3F** の階層を持ちます。

## マスの種類

| マス | 説明 |
| --- | --- |
| スタート | ロボットが最初に配置されるマス |
| ゴール | このマスを通過するとクリア |
| 床 | ロボットが移動できるマス |
| 壁 | ロボットがぶつかるとゲームオーバー |
| 穴 | ロボットが通過すると落下してゲームオーバー |
| ボタン | 通過すると、相手の**鍵**のロックを外す |
| 鍵 | 通過すると、自分の**ゴール**のロックを外す |

## スタート・ゴール・ボタン・鍵

- 各児童ごとに一つずつ設置します。
- 自分のものだけ利用でき、相手のものを通過しても**床**と同じ扱いになります。
- ボタンを押すと相手の鍵のロックが外れ、相手が鍵を取得できるようになります。
- 鍵を取得すると、自分のゴールをクリアできるようになります。
- 鍵は一定の**ターン**数の後に消滅します。ターン数は設定値です。
