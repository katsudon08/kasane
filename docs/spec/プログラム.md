# ロボットを動かすためのプログラム

本サービスは**QRコード**が印字されたカードをカメラにかざすことで、ロボットを動かすためのプログラムを作成します。
一つのカードは一つのコマンドに対応していて、以下五種類のコマンドが存在します。

| コマンド | 説明 |
| --- | --- |
| 前にすすむ | ロボットを一マス前に進める |
| 右にまがる | ロボットを時計回りに90度回転させる |
| 左にまがる | ロボットを反時計回りに90度回転させる |
| 穴をうめる | ロボットの前のマスが**穴**だった場合、**床**に変える。それ以外の場合は何もしない |
| くりかえす | **くりかえす**を含む五種類のコマンドを指定回数分繰り返す。このコマンドだけ、カードで読み込んだ際にモーダルウィンドウで回数入力を行う |

## プログラムの保存

[ロボットについての説明](迷路.md)でも述べられていますが、[予測フェーズ]()と[実装フェーズ]()で相手の動きを予測するためのプログラムが***特定のバージョン**として記録されます。

[予測フェーズ]()では**バージョン1**が、[実装フェーズ]()では**バージョン2以降**が保存されます。

保存のタイミングはそれぞれ異なり、[予測フェーズ]()では**予測を確定して、[実装フェーズ]()へと進む時**に保存され、[実装フェーズ]()では**ゴースト世界をシュミレートするたび**に保存されます。

最終的に[実装フェーズ]()において、**自分のロボットを動かすプログラムをロックしたタイミングのバージョン**のプログラムが後続のフェーズで使用されます。
