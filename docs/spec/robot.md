# ロボット

迷路内でのロボットの動きを記します。

## 動き方

- 自分と相手のロボットは交互ではなく、**同時に**進みます。二台がそれぞれコマンドを一つ実行する単位を**ターン**と呼びます。
- 相手のロボットがいるマスには進めません。二台が同じマスに進もうとした場合は、そのコマンドをスキップして次のコマンドを実行します。
- ゴールに到達したロボットは迷路から**消滅**します。

## ゴースト世界と実体世界

| 世界 | 動くロボット | 動かすプログラム |
| --- | --- | --- |
| **ゴースト世界** | 自分と相手の**ゴースト** | 自分のプログラムと、自分が作った**予測プログラム** |
| **実体世界** | 自分と相手の**実体** | 二人がそれぞれ実際に作ったプログラム |

- 二つの世界は互いに干渉しません。
- ゴースト世界のロボットは**半透明**で描画します。
- 自分のゴーストと自分の実体は、同一のプログラムで動きます。
