# 迷路内のロボットの動き

自分と相手のロボットは交互ではなく、**同時に**進みます。

相手のロボットが存在しているマスには自分のロボットが進むことはできません。
自分のロボットと相手のロボットが同じマスに進もうとした場合は、その**コマンドをスキップして**次のコマンドを実行します。

ロボットがゴールに到達したら、そのロボットは迷路から**消滅**します。

## 予測フェーズ・実装フェーズと実行フェーズでの違い

[児童フロー](児童フロー.md)において、フェーズごとに様々なロボットが登場しているのでそれについての記述を行います。

### 予測フェーズ

ここでは**相手の動きの予測を元に作成したプログラム**で動かせる**相手のロボット**(**ゴースト**と呼称します)を操作します。

このフェーズではまだ、自分のロボットは存在していないので、迷路内に存在しているロボットの数は**一台**です。
[実装フェーズ]()に遷移する際に、プログラムの変更がロックされて**バージョン1**として保存されます。

### 実装フェーズ

ここでは、[予測フェーズ]()に加えて、**自分のロボット**が追加されます。
自分のロボットは**自分が作成したプログラム**で動きます。

また、[予測フェーズ]()で作成したゴーストの動きをここで再度作り直すことができます。
ただし、その動きをシュミレートするたびに**相手の動きを予測するプログラム**の変更は**バージョンX**として保存されます。 (X > 1の数字が入ります)

このフェーズは**ゴースト世界**と呼称され、自分のロボットと相手の動きを予測したロボットの**二台**が存在しています。

### 実行フェーズ

ここでは[実装フェーズ]()で実装したロボット群(ゴースト世界のロボット)に加えて、**自分のロボット**と**相手の実際のロボット**の**四台**が存在しています。

このフェーズは**実体世界**と呼称され、ゴースト世界と実体世界は互いに干渉することはありません。
また、ゴースト世界のロボット群は**半透明**で描画されます。

ゴースト世界と実体世界で相手のロボットについては、明確にプログラムが異なります。
**相手の動きを予測すために作成したプログラム**と**相手が実際に作成したプログラム**という二つのプログラムが存在するためです。

ただし、ゴースト世界と実体世界における自分のロボットについては、**プログラム自体は同一**のものです。
では何によってロボットの動きが変わるのかというと、**相手の実際のロボットの動きの干渉があるかどうか**によってどう動くかが変化します。

一例として、**自分のロボットの動きに相手のロボットの動きが重なってしまう**ような状況で、ゴースト世界とは異なる動きになります。
