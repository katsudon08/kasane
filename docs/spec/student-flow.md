# 児童フロー

児童が授業中にどう進めるかを記します。プログラムの入力手段はすべて **QR カード** です。

## モード

| モード | 内容 |
| --- | --- |
| **シングルモード** | 一台のロボットをプログラムして迷路のゴールを目指す。ProgPath と同じ進め方 |
| **ペアモード** | 二人一組で、それぞれ自分のロボットをプログラムする。以下のフェーズに沿って進む |

## ペアモードのフェーズ

ペアの二人は同じフェーズを進み、どちらかが条件を満たしていない間は次のフェーズに進みません（**バリア同期**）。

```
予測 → 実装 → 説明 → 実行 ─┬─ 二人ともゴール → 振り返り
                          └─ それ以外        → 議論 → 予測（次のラウンド）
```

予測フェーズから議論フェーズまでの一巡を**ラウンド**と呼びます。
どのフェーズでも、自分のプログラムと**予測プログラム**が相手に開示されることはありません。

### 予測フェーズ

| 項目 | 内容 |
| --- | --- |
| 話し合い | できない |
| できること | 相手のロボットの動きを予測した**予測プログラム**を作る。自分のロボットのプログラムは作らない。相手の**ゴースト**単体を走らせて動作確認できるが、自分のロボットはまだ迷路にいないためゴールはできない |
| ロックと保存 | 予測を確定すると予測プログラムがロックされ、**バージョン 1** として保存され、相手に通知される。確定後も動作確認はできる |
| 次へ | 二人とも確定したら**実装フェーズ**へ |

### 実装フェーズ

| 項目 | 内容 |
| --- | --- |
| 話し合い | できない |
| できること | 自分のロボットのプログラムを作る。**ゴースト世界**を何度でも走らせて検証できる。予測の誤りに気づいたら予測プログラムを作り直せる |
| ロックと保存 | ゴースト世界を走らせるたびに、そのときの予測プログラムがロックされ **バージョン 2、3、…** として保存される。自分のプログラムを確定すると、自分のプログラムと予測プログラムの両方がロックされ、相手に通知される。このときのバージョンが以降のフェーズで使われる |
| 次へ | 二人とも確定したら**説明フェーズ**へ |

### 説明フェーズ

| 項目 | 内容 |
| --- | --- |
| 話し合い | できる |
| できること | 自分のロボットをどう動かすつもりか、相手の動きをどう予測したかを口頭で相手に説明する |
| ロックと保存 | なし。説明を聞いて予測の誤りに気づいても、プログラムは修正できない |
| 次へ | **実行フェーズ**へ |

### 実行フェーズ

| 項目 | 内容 |
| --- | --- |
| 話し合い | できない |
| できること | **ゴースト世界**と**実体世界**を重ねて実行した結果を見る。画面には自分と相手の**ゴースト**、自分と相手の**実体**の 4 台が重なって表示される。差分は児童ごとに異なるため、二人の画面の内容は異なる |
| ロックと保存 | なし |
| 次へ | 二人ともゴールしたら**振り返りフェーズ**へ。それ以外（**手数**の超過を含む）は**議論フェーズ**へ |

### 議論フェーズ

| 項目 | 内容 |
| --- | --- |
| 話し合い | できる |
| できること | 差分を手掛かりに原因を考え、改善の方針を話し合う。決めるのは方針であって、プログラムそのものではない。相手の考えは口頭で聞くことでしか得られない |
| ロックと保存 | なし |
| 次へ | 方針が決まったら**予測フェーズ**へ戻り、次のラウンドを始める |

### 振り返りフェーズ

| 項目 | 内容 |
| --- | --- |
| 話し合い | できない |
| できること | 自分が作った予測プログラムと、相手が実際に作ったプログラムを並べて見る |
| ロックと保存 | なし |
| 次へ | なし。最後のフェーズ |
