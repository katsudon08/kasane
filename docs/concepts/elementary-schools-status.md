# 小学校のプログラミング教育の現状

全国調査から分かることと、導入先への聞き取りで把握したことを分けて記す。全国の数値を導入先二校の状況として読み替えず、聞き取りだけで全国の傾向を語らない。

## 全国調査から分かること

### 授業の時間

文部科学省の令和4年度調査（無作為抽出された小学校等1,235校）では、プログラミングに関する年間授業時数は第5学年で平均5.8時間、第6学年で6.7時間だった。0時間と回答した学校はそれぞれ4.8%、1.5%、1〜3時間は35.4%、23.8%だった。

これらは**2022年度の計画**であり、実際に行った授業の記録ではない。また、複数学級のうち一学級でも実施していれば、学年として「実施」と回答されている。したがって、各児童が何時間学んだかまでは分からない。

### 児童の到達度

文部科学省の情報活用能力調査（2022年1〜2月、小学校第5学年4,486人）では、「分岐処理のプログラムの実行結果を考える」「プログラムの不具合から修正すべき箇所を見つける」段階以上に達した児童は8.7%だった。「簡単な分岐処理のプログラミングができる」段階以上は50.1%だった。

この調査は児童の到達度を示すものであり、授業時数の少なさがその原因だと示すものではない。また、KASANEを使えば到達度が上がるという根拠にもならない。

### 授業を支える体制

同じ情報活用能力調査の学校質問調査（小学校161校、校長が回答）では、「情報活用能力の育成の指導事例が不足している」に「あてはまる」「ややあてはまる」と答えた学校が67.7%、「校内の指導体制が不十分」は54.0%だった。質問は**情報活用能力全体**を対象にしており、プログラミングだけの割合ではない。

文部科学省の情報・技術ワーキンググループ資料（2026年5月）は、体験的な活動の不足や、小学校での取組の学校間差を課題として挙げている。これは国の課題認識であり、未実施の学校数を示す統計ではない。

## 導入先について分かっていること

導入を想定しているのは[大洗小学校](https://www.oarai-el.oarai.ed.jp/)と[大洗南小学校](https://www.minami-el.oarai.ed.jp/)である。以下は関係者からの聞き取りに基づく想定を含み、**二校それぞれへの確認はまだ済んでいない**。

- 児童は一人一台のChromeOSタブレットを使い、調べ物、動画、スライド作成などに活用している。
- Scratchなどを使ったプログラミング授業は行っていないと聞いている。
- 小学4年生から始め、5・6年生に広げる構想である。総合的な学習の時間を使い、一学級24人を想定する。
- 校内ネットワークからKASANEに接続できるよう、教育委員会がサーバーのIPアドレスを許可する想定である。
- 前身のProgPathは導入先で実証実験を重ねてきた。

### 教師の受け止めとICT操作

教育委員会は、国が示すプログラミング教育や個別の学びと協働の方向を支持し、KASANEの取組にも賛同している。一方、教育委員会からは、教師の間には「なぜ取り組む必要があるのか」という疑問が多く、ICTの操作を自力で進めることも難しいと聞いている。これは教師本人への調査結果ではなく、二校それぞれの状況もまだ確認できていない。

教師向けのアンケートについても、オンラインフォームでは回答が集まりにくく、紙をその場で記入してもらうと回答が集まりやすいと聞いている。回答する場が設けられるかどうかも異なるため、この差を回答媒体だけの効果とは判断できない。

導入前には、教師本人に授業の意義がどう伝わっているか、教材の準備やICT操作のどこで支援が必要かを確認する必要がある。アンケートを行う場合は、その場で回答できる方法を検討する。
