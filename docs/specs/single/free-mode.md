# 自由モード

授業に参加せず、児童の端末だけで遊ぶモードです。サーバー（API・DB）とは通信しません。
画面・迷路・命令・実行ルールは、このファイルに書いた違いを除き、授業で使うモード（[README.md](README.md)・[domain.md](domain.md)）と同じです。

## 決定事項

| 項目                     | 決定                                                                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 使う場面                 | 授業でAPI・DB・画面の配信のどれかが止まったときと、授業の外で家で遊ぶとき                                                                   |
| 使う端末                 | Webの児童用アプリ（家ではこれが主）と、パソコンに入れるデスクトップアプリ（Windows・Mac）                                                   |
| 入り方                   | Webは入口（`/start`）で「授業に参加する」と「自由に遊ぶ」を選ぶ。デスクトップアプリは入口を出さず、自由モードから始まる                     |
| 児童の識別               | しない。ニックネームは入れず、記録は端末（Webはブラウザ、デスクトップアプリはアプリ）ごとに残す                                             |
| 教師                     | 自由モードの教師の画面はない。進み具合は教師に届かない                                                                                      |
| コンパイル               | 端末で`packages/core`の`compile`を呼ぶ                                                                                                      |
| 保存するもの             | クリア数と自分の迷路だけ。送ったプログラムの記録は残さない                                                                                  |
| 保存先                   | `localStorage`                                                                                                                              |
| 授業で使うモードとの関係 | 記録を共有しない。授業で使うモードのクリア数と自分の迷路は自由モードに持ってこない。続きから始めるときは[問題を飛ばす](#問題を飛ばす)を使う |

## 用語

| 概念       | コード | 児童画面の文言                                                                                   |
| ---------- | ------ | ------------------------------------------------------------------------------------------------ |
| 自由モード | `free` | （出さない。入口のボタンは「<ruby>自由<rt>じゆう</rt></ruby>に<ruby>遊<rt>あそ</rt></ruby>ぶ」） |

## 画面遷移

```
Web
[入口] ──授業に参加する──→ [先生のQRを読みとる]（README.mdの画面遷移）
   │
   └──自由に遊ぶ──→ [ホーム（自由モード）] ──→ 以下はREADME.mdの児童の画面遷移と同じ

[授業がおわりました] ──自由に遊ぶ──→ [ホーム（自由モード）]

デスクトップアプリ
[ホーム（自由モード）]から始まる
```

| ルート                     | 画面                       | 目的                                           |
| -------------------------- | -------------------------- | ---------------------------------------------- |
| `/start`                   | 入口                       | 授業に参加するか、自由に遊ぶかを選ぶ           |
| `/free`                    | ホーム                     | 遊ぶ迷路を選ぶ                                 |
| `/free/tutorials/$no`      | もんだいのしょうさい       | 迷路の形を3Dで確かめる                         |
| `/free/tutorials/$no/play` | プレイ                     | プログラムを作って動かす                       |
| `/free/mazes/new`          | めいろをつくる             | 新しい迷路を作る                               |
| `/free/mazes/import`       | めいろをもらう             | 友だちの迷路のQRを読み取り、自分の迷路にする   |
| `/free/mazes/$mazeId`      | じぶんのめいろのしょうさい | 迷路の形を3Dで確かめ、遊ぶか変えるか消すか選ぶ |
| `/free/mazes/$mazeId/edit` | めいろを変える             | 迷路を作りかえる                               |
| `/free/mazes/$mazeId/play` | プレイ                     | プログラムを作って動かす                       |

- `/free`の下の画面は`/free`のレイアウトの下に置き、児童のトークンを見ない。`GET /me/events`にもつながない
- 授業で使うモードの画面は、児童のトークンが端末にないとき`/start`へ移動する
- 授業QRのURL（`/join?lesson=`）から来たときは、入口を通らない
- 自由モードの画面の「もどる」は、`/free`の下の画面へ移る（授業で使うモードの`/`は`/free`、`/mazes/$mazeId`は`/free/mazes/$mazeId`に読み替える）

## 入口（`/start`）

- 背景は動かない1枚の画像（[背景の画像](#背景の画像)）。画像は飾りとして扱い、見出し「KASANE」は読み上げ用にだけ置く
- 画面の下のほうに白い面を置き、その上にボタンを横に並べる（幅が足りない画面では縦に並べる）
  - 「<ruby>授業<rt>じゅぎょう</rt></ruby>に<ruby>参加<rt>さんか</rt></ruby>する」: `/join`へ
  - 「<ruby>自由<rt>じゆう</rt></ruby>に<ruby>遊<rt>あそ</rt></ruby>ぶ」: `/free`へ
  - 二つは同じ大きさ・同じ色にし、どちらも主ボタンにしない
- 画面の右上に「パソコン<ruby>用<rt>よう</rt></ruby>のKASANEをダウンロードする」（副。二つのボタンより小さく）
  - WindowsかMacで開いたときだけ出す。iPad・Chromebook・スマートフォンでは出さない
  - iPadのSafariはMacと名乗るので、タッチできる端末はMacとみなさない
  - 押すと、そのOSのインストーラーのダウンロードが始まる（[配布](#配布)）

### 背景の画像

- Three.js（`three`）で組んだ3Dの場面を書き出した画像を使う。場面を組むコードはリポジトリに置き、書き出し直せるようにする
- 雲の海に浮かぶ雲の上にロボットが立ち、空に「KASANE」の文字を積み上げている場面にする
  - 「KASANE」の文字は、小さな立方体を並べたピクセルの立体を3枚の層にし、少しずつずらして重ねる
  - いちばん手前の層は一部が欠けていて、欠けた所へロボットから立方体が運ばれていく
  - ロボットは、画面の3Dのロボットと同じ作りを、立方体で組み直したピクセル調にする
- 迷路のマスや命令カードは描かない
- 色の基調は青と白で、昼の明るい空にする
- 形と色だけで見せる。光らせるのはロボットの目だけにし、ぼかしや光の粒などの演出は入れない
- 横長（16:9）と4:3のどちらで切り取られても、「KASANE」の文字とロボットが切れない構図にする
- 「KASANE」の文字は、ボタンに隠れないよう画面の上のほうに置く。ボタンを置く下のほうと、ダウンロードのボタンを置く右上には物を少なくする
- 書き出す場面には、画面の3Dの決まり（後処理を入れない、影を使わないなど）を当てはめない
- 書き出した画像はビルドに含める（外から読み込まない）

### 問題を飛ばす

- 「<ruby>問題<rt>もんだい</rt></ruby>を<ruby>飛<rt>と</rt></ruby>ばす」を押すと、すぐに「どの<ruby>問題<rt>もんだい</rt></ruby>から<ruby>始<rt>はじ</rt></ruby>める？」のモーダルを出す
- 選べる問題、主ボタン、飛ばした後の動きは授業で使うモード（[README.md](README.md#問題を飛ばす)）と同じ

### 問題をリセットする

- ホームの「問題を飛ばす」の右に「<ruby>問題<rt>もんだい</rt></ruby>をリセットする」（副）を置く。クリア数が0のときは出さない
- 押すと確認のモーダルを出す
  - 文言は「<ruby>問題<rt>もんだい</rt></ruby>をリセットすると、1<ruby>問目<rt>もんめ</rt></ruby>からやり<ruby>直<rt>なお</rt></ruby>しになるよ。<ruby>自分<rt>じぶん</rt></ruby>の<ruby>迷路<rt>めいろ</rt></ruby>は<ruby>消<rt>き</rt></ruby>えないよ」
  - ボタンは左に「<ruby>問題<rt>もんだい</rt></ruby>をリセットする」（枠だけ）、右に「このまま<ruby>続<rt>つづ</rt></ruby>ける」（青の塗りつぶし）
- 「問題をリセットする」を押すと、クリア数を0にしてモーダルを閉じる
- 自分の迷路は消さない。チュートリアルをすべてクリアし直すまで、ホームの「自分の迷路」は鍵のかかった表示に戻る

## 記録

| `localStorage`のキー       | 中身                                                                       |
| -------------------------- | -------------------------------------------------------------------------- |
| `kasane.free.clearedCount` | クリア数（0〜チュートリアルの数の整数）                                    |
| `kasane.free.mazes`        | 自分の迷路の配列。要素は`{ mazeId, name, data, createdAt, updatedAt }`の形 |

- クリア数の変わり方

| 操作                           | 新しいクリア数                     |
| ------------------------------ | ---------------------------------- |
| チュートリアル`no`でゴールした | 今のクリア数と`no`の大きいほう     |
| `to`問目から始めるよう飛ばした | 今のクリア数と`to - 1`の大きいほう |
| 問題をリセットした             | 0                                  |
| 失敗した・自分の迷路で遊んだ   | 変わらない                         |

- 挑戦できるかは`isTutorialUnlocked`、迷路を作れるかは`canCreateMaze`で決める（授業で使うモードと同じ）
- 迷路の`mazeId`は`crypto.randomUUID()`で作る。`createdAt`と`updatedAt`はISO 8601の文字列にする
- 新しく作ったときとQRでもらったときは要素を足し、変えたときは`name`・`data`・`updatedAt`を置き換え、消したときは要素を除く
- 保存する前に、名前は[backend.md](backend.md#入力の上限)の迷路の名前と同じ決まりで、`data`は`validateMaze`で確かめる。通らなければ保存しない
- 一覧の並びは`updatedAt`が新しい順、同じなら`mazeId`順（`GET /me/mazes`と同じ）
- 自分の迷路で遊んでも、何も保存しない
- 読み出すときに確かめる
  - JSONとして読めない値は、無いものとして扱う
  - クリア数が0〜チュートリアルの数の整数でなければ、0として扱う
  - 迷路は一つずつ、形（backend.mdの入力の上限と同じ範囲）と`validateMaze`を確かめ、通らないものは一覧に出さない
- `localStorage`への書き込みに失敗したときは想定外とし、[うまく動かなかったときの受け止め](README.md#うまく動かなかったときの受け止めエラーバウンダリー)に任せる
- iPadのSafariが、しばらく使われなかったサイトの保存を消すことには対策しない

### フロントエンド

- 記録の読み書きもTanStack Queryで扱い、読み書きの関数は`async`にする
  - クエリのキーは授業で使うモードと分け、`["free", ...]`にする
  - `staleTime: Infinity`にし、書き込んだら無効化する
  - `networkMode: "always"`にする（ネットにつながっていなくても読み書きする）
- 自由モードの画面は外部と通信しない。フォント・QR読み取りのWASM・ロボットのモデル・背景の画像はビルドに含める

## デスクトップアプリ（`apps/desktop`）

- Electronで、`apps/student`のビルドを同梱して開く
- 起動すると`/free`を開く。`/free`の外のルートを開こうとしたら`/free`へ移る
- 入口がないので、ダウンロードのボタンも、ホームの「もどる」も出さない
- ネットにつながっていなくても、すべての画面が使える
- カメラは、アプリの画面にだけ許可する
- CSPは児童用アプリ（[backend.md](backend.md#そのほかのセキュリティ設定)）と同じ指示にし、`connect-src`は`'self'`だけにする

### 配布

- インストーラーはWindows（x64）とMac（Apple SiliconとIntelのどちらでも動く1つのファイル）の二つ
- GitHub Actionsで作り、GitHubのReleasesに置く。`main`に付けた`v`で始まるタグを押したときに作る
- ファイル名に版を入れず、`KASANE-Setup.exe`（Windows）と`KASANE.dmg`（Mac）にする
- 入口のダウンロードのボタンは`https://github.com/katsudon08/kasane/releases/latest/download/{ファイル名}`を指す
- 署名はしない。警告が出たときの開き方は手順書（[docs/deploy.md](../../deploy.md)）に書く
